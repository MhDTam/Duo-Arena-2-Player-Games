### 🌟 Key Features (English)
- **65+ Diverse Mini-Games:** Action, sports, brain puzzles, arcade classics, and real-time 2D physics battles (powered by planck.js).
- **Smooth 60 FPS Multiplayer:** Ultra-responsive real-time multiplayer driven by an authoritative Node.js WebSocket engine with client snapshot interpolation.
- **Play vs Bot (Offline & Solo):** Advanced on-device AI bots with multiple difficulty levels (Easy, Normal, Hard) that require zero server lag.
- **Dual Language & RTL Support:** Native support for both English and Arabic with automatic right-to-left layout.
- **Cross-Platform Responsive Design:** Built for touchscreens (floating joystick & gestures), desktop keyboards (WASD / Arrows), and native Android APK.
- **Instant Reconnect & Social Features:** 15-second graceful reconnection window, live ping indicator, emoji reactions, player profiles, and daily missions.

### 🌟 المميزات الرئيسية (العربية)
- **أكثر من 65 لعبة مصغرة ومتنوعة:** ألعاب حركة، رياضة، ذكاء، وتحديات فيزياء واقعية ثنائية الأبعاد لشخصين.
- **لعب جماعي سلس بـ 60 إطار في الثانية:** مزامنة أونلاين فائقة السرعة والاستجابة عبر سيرفر Node.js WebSockets وخوارزميات سلاسة الحركة.
- **اللعب الفردي ضد البوت (أوفلاين):** ذكاء اصطناعي يعمل محلياً على جهازك مباشرة بمستويات متعددة (سهل، متوسط، صعب) بدون أي تأخير.
- **واجهة كاملة باللغتين العربية والإنجليزية:** دعم كامل للنصوص العربية واتجاه اليمين إلى اليسار (RTL).
- **متوافقة مع كل الأجهزة:** تحكم لمسي مخصص للهواتف، دعم لوحة المفاتيح للحواسيب، وتطبيق أندرويد مخصص.
- **استعادة الاتصال والتفاعل:** إمكانية العودة للمباراة خلال 15 ثانية عند انقطاع الشبكة، مع تفاعلات الإيموجي والملف الشخصي والمهام اليومية.

# رفع السيرفر مجاناً (Render) — خطوة بخطوة

السيرفر المجاني بـ Render: ما يحتاج بطاقة، يدعم WebSocket، منطقة Frankfurt (قريبة من العراق).
العيب الوحيد: إذا ماكو أحد يلعب 15 دقيقة ينام، وأول واحد يفتح اللعبة ينتظر تقريباً دقيقة لحد ما يصحى (اللعبة تعرض رسالة "جاري تشغيل السيرفر").

## 1) ارفع المشروع على GitHub
- الأسهل: **GitHub Desktop** → File → Add local repository → اختار فولدر `duo-arena` → Publish repository (خليه Private أو Public، الاثنين يشتغلون).
- الملفات اللي ما لازم ترفع (node_modules و build) مستثناة تلقائياً بـ `.gitignore`.

## 2) سوّي السيرفر على Render
1. ادخل https://render.com وسجّل بحساب GitHub.
2. **New → Blueprint** → اختار الـ repo مالتك → Render يقرا ملف `render.yaml` لحاله.
3. اضغط **Apply**. البناء ياخذ 2–4 دقائق.
4. الرابط راح يكون: `https://duo-arena-ali313.onrender.com`
   - افتحه بالمتصفح: لازم تطلع اللعبة. و `…/health` يرجع `{"ok":true}`.
   - إذا Render عطاك اسم ثاني، غيّر الرابط بملف `client/src/config.js` وبلّغني حتى أبني APK جديد (أو اكتبه من ⚙️ داخل التطبيق).

## 3) (اختياري) خلّيه صاحي دائماً — مجاناً
- سجّل بـ https://uptimerobot.com → Add New Monitor → HTTP(s)
- URL: `https://duo-arena-ali313.onrender.com/health` — كل 5 دقائق.
- هيچ السيرفر ما ينام (الـ 750 ساعة المجانية بالشهر تكفي خدمة وحدة 24/7).

## 4) التطبيق
- `DuoArena-debug.apk` مبني ومعرّف عليه الرابط أعلاه. نصّبه وافتح اللعبة مباشرة.
- اللعب من المتصفح: نفس الرابط، وتگدر تدز رابط الغرفة لصديقك بالواتساب.

## بعدين (إذا كبرت اللعبة)
Oracle Cloud Always Free (سيرفر حقيقي مجاني، يحتاج بطاقة للتحقق) أو VPS بـ 4–5$ — ملفات Docker + Caddy جاهزة بفولدر `deploy/`.
